# Security policy

Do not report suspected vulnerabilities in a public issue, discussion, or pull request.

Once this project is hosted, the owner should enable GitHub private vulnerability reporting. Use the repository's **Security** tab to submit a private report when that feature is available. If private reporting is not available, contact the project owner through a verified private channel and do not include exploit details in public.

There is no hosted repository or configured private reporting endpoint yet. Public release must wait until the owner verifies and enables a suitable private reporting route.

Please include the affected version or commit, relevant environment, impact, and a minimal safe reproduction. Do not include ROMs, BIOS, saves, credentials, or personal data.
