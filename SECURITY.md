# Security policy

Do not report suspected vulnerabilities in a public issue, discussion, or pull request.

The owner should enable GitHub private vulnerability reporting. Use the repository's **Security** tab to submit a private report when that feature is available. If private reporting is not available, contact the project owner through a verified private channel and do not include exploit details in public.

The repository is hosted at [mharoonfsd/pegasus-arm-opi5](https://github.com/mharoonfsd/pegasus-arm-opi5), but no private reporting endpoint has been verified or configured. The owner should enable GitHub private vulnerability reporting and confirm it works before inviting security reports or making a public release.

Please include the affected version or commit, relevant environment, impact, and a minimal safe reproduction. Do not include ROMs, BIOS, saves, credentials, or personal data.

CI runs static checks and scans added/modified files for secrets. These checks are not a guarantee that code is safe and do not replace responsible disclosure, human review, dependency/provenance checks, or an audit of Git history before a public release.
